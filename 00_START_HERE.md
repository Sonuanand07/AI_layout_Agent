## 💡 HELPFUL TIPS

### **Before You Start**
- ✅ Make sure Node.js is installed (`node --version`)
- ✅ Make sure Git is installed (`git --version`)
- ✅ Have your API key ready

### **During Setup**
- ✅ Don't skip the `setup.bat` script - it does everything
- ✅ When it asks for API key, use the one from Step 1
- ✅ Don't share your API key with anyone

### **During Deployment**
- ✅ Make sure to add the `ANTHROPIC_API_KEY` variable to Vercel
- ✅ If deployment fails, check Vercel logs
- ✅ Test your live URL before submitting

### **Before Submitting**
- ✅ Test the live app works

## 🆘 IF SOMETHING GOES WRONG

### Common Issues Quick Fixes

| Issue | Fix |
|-------|-----|
| "npm: command not found" | Install Node.js from nodejs.org |
| API key error | Edit server\.env and add your key |
| "Cannot connect to server" | Make sure `npm run dev` is running |
| Vercel won't deploy | Check environment variables in Vercel |
| Live app shows 404 | Refresh page or wait 5 minutes |

**For more help**: See **TROUBLESHOOTING.md** in your project
